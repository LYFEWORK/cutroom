# The sound kit

Every file in this folder is generated by `../sfx_synth.py` from noise and envelopes. Nothing here was recorded, downloaded or licensed, so the whole
folder can ship and be copied freely. Run `python3 engine/sfx_synth.py` to write it again; a fixed seed makes the files come out byte for byte the same.

All files are 48 kHz mono wavs with a peak of -6 dBFS. The mix (`sound.py`, the sfx budget) puts each one far under the voice, never on a word.

| family | files | what it is for |
|---|---|---|
| `click` | `click-1..3` | a crisp UI or camera-button click: a graphic landing, a row appearing, a cut inside a run of footage |
| `pop` | `pop-1..3` | a small pop: a card or chip arriving |
| `punch` | `punch-1..3` | a soft low punch: a hard cut, a big line landing |
| `shutter` | `shutter-1..3` | a camera shutter: a full-screen entrance |
| `whoosh` | `whoosh-1..4`, `whoosh`, `whoosh-out` | a sweep for an entrance or an exit (asked for by name) |
| `swish` | `swish-1..2`, `swish` | a short sweep for a punch-in (asked for by name) |
| `tick` | `tick-1..2`, `tick` | a glass tap (asked for by name) |
| `thud` | `thud` | one low payoff sound (asked for by name) |

`click`, `pop`, `punch` and `shutter` are the four families the sfx budget needs: `sound.py kit` checks them. To use your own sounds instead, put
files with the same names in a folder and set `sfx_dir` in `~/.cutroom/config.json`; a family found there wins over this folder.
